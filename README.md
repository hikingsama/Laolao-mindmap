## 角色工作流与提问链（2026-10-19）

- 侧栏显示真实的“关联与定向→生成回答”进度。完成后收成一行，展开可查看角色职责、回答方向和来源快照；点击来源定位节点。
- 在输入区展开“回答方向与参考范围”，可指定解释方向，或限制为当前节点/当前树。默认参考当前树和相关树。
- 提问入口上方显示任务状态，点击“查看过程”可回到该次记录。母链与子链采用不同颜色，连线优先使用空闲磁吸点；四点全占时使用错位接点。
- 同树各节点的提问历史统一保存在导图的aiMemory字段中，换节点可沿母链继续追问；相关树作为有出处的参考，树的归属保持独立。
- 当前两个角色复用已配置模型。每次正常提问包含一次关联请求和一次回答请求；关联失败时明确显示已退回路径资料。尚未启用独立检查员。
- 流式消息包装和思考片段单独计数，不占回答正文额度。关联内容异常时使用当前节点与上游路径继续回答；正文确实过长或被模型截断时，提示会说明原因，已生成节点保留，可从最后一个节点继续提问。
- 旧版浏览器内各节点的历史在打开提问侧栏时合并到恢复草稿；原浏览器记录保留。Ctrl+S后随导图正式保存，导出JSON也包含历史。
- 撤销移除生成节点时保留原始问答与来源记录；历史不会随撤销恢复为半截回答。

## 直接生成导图更新


- 每次提问直接生成一组导图节点；历史对话仅用于理解追问，本次输出不重新整理此前回答。
- 完整知识点随模型返回依次进入主画布，连线随端点齐备后加入；新版采用关联与定向、回答两个角色，分别使用当前模型完成一次请求。
- 移除小导图预览、预览编辑、手动整理和推送。生成后双击主画布节点直接编辑。
- “第X次提问：问题内容”仅作为本组独立入口，知识点标题不重复提问编号。
- 拖动提问侧栏左边界调宽，记住上次宽度；小窗口改为覆盖显示。拖柄可用方向键调整，双击恢复默认。
- 打开提问侧栏时，顶栏与剩余画布一起收缩；用户消息靠右、回答靠左。标题栏和节点信息采用紧凑布局。
- 图片/PDF节点提问自动附带文件，附件设置区已移除。PDF默认读取全部页面；在问题中写“只看第2–4页”可指定范围，“第五题”不会当作页码。前后端不再限制最多6页。
- 桌面提问侧栏顶部与顶栏顶部对齐，利用原先空白处。每次提问入口下方附带可折叠学习清单：阅览、提炼、亲笔推导、对比权威答案；手动勾选，随导图保存。生成完成不自动标记学完，Markdown导出保留复选状态。
- 撤下 GLM-image 生图入口及接口。已有图片、图片/PDF提问和各服务商的本机密钥保留。
- 停止或传输失败时保留已完成节点；正常情况下每次生成可一步撤销。期间的其他编辑按正常操作顺序撤销，不会重新出现半截生成结果。
- 保留非画布防误缩放、单行公式分步推导、PDF内部标题栏。公式正文按完整节点渲染，尊重减少动画设置。
