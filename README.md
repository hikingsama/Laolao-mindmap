# Laolao-mindmap · 捞捞思维导图（独立版）

## 当前版本：平级节点与自动转弯连线（2026-10-14）

以下说明优先于后面的第一版历史记录。

- 暂停父子关系：所有节点平级，删除只删除当前节点及其连接，不删除其他节点。
- 新增按钮、Tab、Enter 和双击空白创建独立节点；新增不自动连线。进入节点编辑后 Enter 换行、Ctrl+Enter 保存。
- 新建空白导图及新节点不预填文字；保存空文本或清空已有文字时不会补上默认主题。导图列表使用“未命名导图”作为名称，不写入节点正文。
- 单击节点只选中，普通字符键和 F2 不会进入文本编辑；双击节点才修改现有文字。双击空白仍新建节点，触屏双击节点同样可编辑。
- 原有导图打开时先保留/补齐位置，再将节点展开为平级列表。已有显式连线保留，旧父子渲染线已移除。
- 节点可自由拖动，包括原中心节点；大纲是平级列表，暂时不提供缩进或按层级折叠。
- 从磁吸点拖到另一节点建立连接。两端磁吸点固定为建线时选定的点，不自动切换；连线向外伸出后以直角折线绕开两端节点，移动或改尺寸后只重算路径。
- 连线路径不改变连接的两个节点、磁吸点或箭头方向。右键连线可设置无箭头、正向、反向、双向或删除。
- 画布显示、连线点击命中、PNG 导出使用同一套路由。JSON 保留全部节点、坐标、尺寸与连接；Markdown/TXT 导出全部节点文字。
- 数据仅保存在当前浏览器，不提供云同步。

运行方式保持不变：`node server.js`，打开 `http://127.0.0.1:8788/`。

当前验证：`node tools/smoke.js` 检查平级迁移、独立删除、新增、路由避让和保存；`node tools/verify-ui.mjs` 用隔离浏览器验证真实拖动、折线命中、删除/撤销及 PNG 导出。旧父子模型的测试只作历史参考，可加 `--legacy` 运行，不作为当前验收标准。

当前路由优先避开连接的两端节点，尚不保证避开第三个节点或其他连线。两端节点重叠或紧贴而挡住选定磁吸点时，应先拖开。

## 节点 Markdown 与数学公式

双击节点打开源码编辑器和实时预览；单击选中后直接打字不会修改节点文字。屏幕较窄时编辑器和预览上下排列。

右上角的“补全快捷键”按钮可打开右侧参考栏，列出当前实际支持的 79 个补全命令、展开结果、编号填写顺序、编辑快捷键和公式写法。按基础结构、初等函数、极限、微分、积分、级数、常用公式、线性代数、符号分组，可按中文名称、命令或填写项搜索。可以在节点编辑时打开和搜索，内容会保留；关闭侧栏可继续编辑。

- Markdown：标题、粗体、斜体、删除线、引用、有序/无序列表、任务列表、链接、表格、行内代码及代码块。
- 行内公式：`$E=mc^2$` 或 `\(E=mc^2\)`。
- 独立公式：`$$\frac{1}{2}+\sqrt{x}$$` 或 `\[\frac{1}{2}+\sqrt{x}\]`，可写成多行，支持 KaTeX 的矩阵、aligned、cases 等数学环境。
- 输入时实时预览，数据仍然是节点的 `text` 原始字符串；JSON 和 Markdown 导出保留源码，PNG 导出保留渲染效果。
- Enter 换行；Ctrl/Cmd+Enter 保存；点击编辑器外保存；Esc 取消本次修改。编辑器内 Tab 不会新建节点。
- 数学区域输入命令后按 Tab 展开；`□` 是独立填空位置。Tab 前进、Shift+Tab 返回已填项，全部填好后移到模板末尾；编辑框下方提示当前项名称及进度。支持在当前填写项内继续嵌套补全，嵌套模板完成后回到外层下一项。不自动替换普通文字；尚不包含 LaTeX Suite 的全部规则或自动片段引擎。
- 保存较长富文本时节点会扩展到容纳内容，坐标不变。之后仍可从边/角调整尺寸；缩小后内容可滚动查看。

错误公式会以红色源码显示，未闭合公式保留为普通文字，代码块和转义美元符号不会参与公式解析。使用 KaTeX 数学语法，不编译完整 `.tex` 文档；暂不支持 Obsidian 的笔记链接、文件嵌入、脚注或插件语法。Markdown 图片暂显示替代文字，不加载远程图片；原始 HTML 不执行。

实现参考： [Obsidian Canvas 文档](https://obsidian.md/help/Plugins/Canvas)、[LaTeX Suite 源码与片段上下文](https://github.com/artisticat1/obsidian-latex-suite)。未复制其插件代码；使用本地 Markdown-it、KaTeX 与 html-to-image，许可证和体积见 [THIRD-PARTY.md](THIRD-PARTY.md)。仍然只需 `node server.js` 启动，页面运行不依赖 CDN。

### 高等数学与线性代数补全

例如，先写 `$int$`，将光标放在 `int` 后、结尾 `$` 前，按 Tab：

| 命令 | 填写顺序 |
| --- | --- |
| `int` / `dint` | 下限 → 上限 → 被积函数 → 微分变量（只填 `x`，不用再输入 `dx`） |
| `uint` | 被积函数 → 微分变量 |
| `iint` / `iiint` | 积分区域 → 被积函数 → 各微分变量 |
| `lim` / `liml` / `limr` | 变量 → 趋近点 → 函数或表达式 |
| `lim2` | 第一变量 → 第二变量 → 第一趋近坐标 → 第二趋近坐标 → 函数 |
| `sum` / `prod` | 指标 → 起始值 → 终止值 → 通项 |
| `der` / `pder` | 函数 → 求导变量 |
| `mat2` / `mat3` / `det2` / `det3` | 逐行、从左到右填写各元素 |
| `solve` | 系数矩阵 → 未知向量 → 常数向量 |
| `charpoly` | 矩阵 → 特征值变量 |

定积分第三项可输入 `frac` 后按 Tab，分别填分子、分母；填完后自动进入积分的微分变量。已填内容长度改变时，后续填空位置会跟随调整。重新打开尚有 `□` 的源码时可用 Tab / Shift+Tab 简单跳转，但当前项名称和嵌套会话只在本次补全中保留。

模板以一年级高等数学与线性代数的常用结构为范围，课程参考：[高等数学（一）](https://www.icourse163.org/course/detail.htm?cid=1001771009)、[线性代数与解析几何](https://syxt.xjtu.edu.cn/info/1018/2125.htm)。验证：`node tools/verify-completion.cjs` 逐个检查所有模板、渲染及填空导航；`node tools/verify-ui.mjs` 检查真实输入流程。

## 怎么跑（写死，不用改参数）

```bash
node server.js
```

然后打开：

```
http://127.0.0.1:8788
```

端口**固定 8788**，不随机、不跟随参数。零依赖，不需要 `npm install`。
（`npm start` 等价于 `node server.js`。）

## 自带自测

先在一个终端跑 `node server.js`，再在另一个终端跑：

```bash
node tools/smoke.js
```

它会启一个浏览器环境仿真台，把 `vendor/mindmap.js` 真跑起来，逐条验证验收情况。

### 可选：UI 级验收（需要真实浏览器）

自测台没有真实布局/命中测试，以下几条要真浏览器才算数。装着 Edge（或 Chrome）时可以一条命令跑完：

```bash
node tools/verify-ui.mjs                 # 默认 http://127.0.0.1:8788/
node tools/verify-ui.mjs --port 9000     # 换端口（或 --url http://… --edge <exe> 指定浏览器）
```

它是**开发工具**，不参与运行时：不被打包、不影响 `node server.js`，也不写仓库（临时浏览器 profile 建在系统临时目录、结束即删）。
验的是：页面能开、双击空白建点中心落在鼠标点、收起按钮第 1 次点就生效、删整棵子树后导图层无孤儿、撤销"新建"后无孤儿。
需要 Node ≥ 22（用到内置 WebSocket），且服务已在跑。

## 数据契约（第 10 条：定下即 API 契约）

```js
cur.pos   = { "<节点id>": { x: 378, y: -120 } }   // x/y   = 节点左上角，舞台坐标系
cur.size  = { "<节点id>": { w: 180, h: 56  } }    // w/h   = 节点宽高，单位与 pos 同一坐标系
cur.fold  = { "<节点id>": true }                  // 折叠状态（只有被折叠的节点有条目）
cur.edges = [ { id, from: { node, side }, to: { node, side }, dir } ]
cur.nodes = [ <容器根节点> ]                       // 节点集合入口是**数组**（不参与布局/样式/折叠）
```

- **全部在导图层，绝不写进节点字段**：安卓端 `MindMapDocument.normalizeNode()` 是白名单式过滤，节点字段会被静默丢掉（硬规则第 2 条）。
- `edges[].from/to.side ∈ n | e | s | w`（磁吸点）；`dir ∈ none | fwd | rev | both`；**端点不落盘坐标**，每次渲染现算。
- 层级（父子关系）由**边**表达；节点上的 `children` 只剩两个用途：**迁移来源**（旧图首次打开时变成 fwd 边）和**枚举**节点。
- **折叠 = 边的可达集合**：遍历种子 = 容器根 ∪ **一条都没有边的节点**（无边 ≠ 被折叠，孤岛照样画出来）；被折叠节点自身可见、不再往外传；环用 `visited` 防死循环。
- `pos` 没有条目的节点仍按旧布局算法排，只是会被挪开避免压在一起。
- `size` 的不变量：
  1. 没有条目的节点，用它**当次文本测量结果**固化一次，之后不再重算（F5 重开不重算已固化值）；
  2. **下限 60×40**；**上限 = 该节点文本测量尺寸的 4 倍**（`clampSize()` 换算）。读取时也会过一遍 clamp，防手改/导入的 JSON 里出现 1×1 或 99999×99999。

## 鼠标交互

### 节点右键菜单与 AI 对话

右键节点可选择「修改样式」或「提问」。样式入口已从工具栏移入右键菜单，仍使用原来的颜色、加粗、标记、进度、备注和链接面板。

「提问」打开右侧 AI 对话栏，发送问题时会带上该节点源码及直接相连节点的内容。每个节点的聊天历史独立保存在本机浏览器；回答支持 Markdown / LaTeX。Ctrl / Cmd + Enter 发送，Enter 换行，正在回答时可停止；失败会保留问题供重试。

每条 AI 回答下方提供「修改思维导图」和「刷新画布渲染」。点击修改先让 AI 生成约200字的简短总结，在对话栏预览；字数是建议，不拦截较长总结，也不截断公式。标题为 Markdown 一级标题 `# 第X次提问：讨论内容总结`，X 是该提问节点的对话轮次；标题换行自动合并，空标题使用「讨论总结」，不限制标题长度。按钮随后变为「推送」，满意后点击才创建旁边的新节点 B，并生成 B 指向原提问节点 A 的箭头；不满意可继续提问。总结保留为草稿，不直接复制整段回答；重复点击不会重复创建，推送的节点和箭头可一次撤销。刷新入口重新绘制当前画布，保留现有坐标和连接关系。

本次发布已移除本机 Codex 接入，不需要 CLI、ChatGPT 登录或 API Key。AI 后端目前只返回“尚未接入模型”的明确提示；新回答和新总结暂不能生成，已有历史总结的推送、节点创建和箭头功能保留。浏览器测试通过模拟接口验证完整流程，不产生真实模型调用。

实现文件：`js/ai-sidebar.js`（侧栏）、`js/ai-server.cjs`（本机接口）、`vendor/mindmap.js`（菜单与刷新）。接口限定本机来源，单请求最多 64 KiB，最多同时处理两个问题。

为后续模型接入保留异步任务前端：提交问题、短请求取回答、停止任务和失败后保留输入。目前 `GET /api/ai/status` 返回 `available:false`，`POST /api/ai/chat` 返回 HTTP 503。队友可从 [TEAM-HANDOFF.md](TEAM-HANDOFF.md) 查看文件职责、接口契约和研究入口。运行 `node tools/verify-ui.mjs` 验证模拟接口及真实未配置状态。

| 操作 | 效果 |
|---|---|
| 拖节点 | 自由定位（写 `cur.pos`）；**拖父节点子节点不动**（位置属于每个节点自己） |
| 拖空白 | 平移画布（滚轮横向/纵向滚动，Ctrl+滚轮缩放） |
| 点节点 | 选中；**选中后右下角出现缩放柄** |
| 拖缩放柄 | 改 `cur.size`，松手才落盘（整段拖拽只进一条撤销历史）；**按住 Shift 锁比例** |
| 双击空白 | 新建一个**自由点**（先算一次尺寸与坐标、立刻固化，不压任何节点）。它**本来就没有边**——无边是合法状态，不会为了「看得见」硬塞一条线 |
| 拖磁吸点（节点四边中点的圆点） | 连一条线；松在另一个磁吸点上就成边 |
| 点线 / 右键线 / Delete | 选中线（屏幕 10px 命中带）；右键改指向（无箭头 / A→B / B→A / 双向）或删除；Delete 删选中的线 |

## 第一版不做

自动布局开关 /「一键整理重排」、云同步（`mm_save` / `CCAuth` 全部打桩或剥离）、回灌主站、构建工具链重构。

## 已知限制

1. 本机直连 `github.com` 不通（TCP 超时），推送需要走本机代理并在**仓库本地** git 配置里设 `http.sslBackend=openssl`；token 需要 `Contents: Read and write`。这些都是**这台机器的环境**，不是项目要求，所以没有写进仓库。
2. 层级（父子关系）由**边**表达。把一张图的所有线删光之后，节点会全部变成互不相干的**孤岛**（都还看得见，但**没有上下级关系**了）—— 这是"边是唯一关系源"的直接后果，不是 bug。
3. 旧导图的播种只做一次，之后位置就是数据，不会自动重排。
4. 仓库里有**两份**导图代码：`vendor/mindmap.js`（页面实际加载的那份，含坐标改动 + 云同步已停用）和根目录 `mindmap.js`（早期"停用云同步"的基线副本，页面不加载）。合并成一份还没做 —— 这是已知的重复，不是设计。
5. **尺寸上下限**：下限 `60×40`，上限 = 文本测量尺寸的 4 倍。上限是"防误拖到离谱"的护栏，不是设计上的美学标准，后续可调。
6. **缩放柄的鼠标交互只能在真实浏览器里验**：本地自测台（`tools/smoke.js`）没有真实布局引擎，验证的是**数据层**（`cur.size` 生成、clamp 边界、落盘、二次打开不重算），按下/拖动/松手这条链路它测不了，已显式标注"未覆盖"。
7. **改尺寸可能推动"没被拖过"的节点重排**：尺寸在 `measure()` 之后、写进布局表之前就合并（这样 `span()` 的子树跨度缓存才按最终尺寸算），因此**没有固化坐标的节点**会按新尺寸重新参与打包而移动。**播种完成后所有节点都有固化坐标，所以正常情况下看不到这个影响**；只有新建/导入进来、还没落过坐标的节点会受影响。这条是设计的必然结果，不是 bug。
