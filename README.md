## 课件、讲义与提示词（2026-10-21）

首页“课件 / 讲义生成导图”支持多PDF、顺序调整、按讲义分支或跨讲义主题融合。逐份选择“嵌入到导图”，保留可阅读PDF节点；不勾选仍解析并保留出处。完整读取、分批调用已有模型，流式生成、可停止及整轮撤销；融合的详细章节可从生成记录展开，不再次调用模型。PPT/PPTX先导出PDF。

顶栏“提示词与过程”查看集中于prompts目录的九份模板，以及实际调用版本、输入、输出和文件页码覆盖。入口只读，可手工改模板供后续调用使用；用户自定义编辑器留待后续。详见[文件生成说明](docs/file-to-mindmap-spec.md)与[提示词维护](docs/prompt-investigation.md)。

## 角色工作流与提问链（2026-10-19）

- 侧栏显示真实的“关联与定向→生成回答”进度。完成后收成一行，展开可查看角色职责、回答方向和来源快照；点击来源定位节点。
- 在输入区展开“回答方向与参考范围”，可指定解释方向，或限制为当前节点/当前树。默认参考当前树和相关树。
- 提问入口上方显示任务状态，点击“查看过程”可回到该次记录。母链与子链采用不同颜色，连线优先使用空闲磁吸点；四点全占时使用错位接点。
- 同树各节点的提问历史统一保存在导图的aiMemory字段中，换节点可沿母链继续追问；相关树作为有出处的参考，树的归属保持独立。
- 当前两个角色复用已配置模型。每次正常提问包含一次关联请求和一次回答请求；关联失败时明确显示已退回路径资料。尚未启用独立检查员。
- 流式消息包装和思考片段单独计数，不占回答正文额度。关联内容异常时使用当前节点与上游路径继续回答；正文确实过长或被模型截断时，提示会说明原因，已生成节点保留，可从最后一个节点继续提问。
- 旧版浏览器内各节点的历史在打开提问侧栏时合并到恢复草稿；原浏览器记录保留。Ctrl+S后随导图正式保存，导出JSON也包含历史。
- 撤销移除生成节点时保留原始问答与来源记录；历史不会随撤销恢复为半截回答。

## 直接生成导图更新


- 每次提问直接生成一组导图节点；历史对话仅用于理解追问，本次输出不重新整理此前回答。
- 完整知识点随模型返回依次进入主画布，连线随端点齐备后加入；新版采用关联与定向、回答两个角色，分别使用当前模型完成一次请求。
- 移除小导图预览、预览编辑、手动整理和推送。生成后双击主画布节点直接编辑。
- “第X次提问：问题内容”仅作为本组独立入口，知识点标题不重复提问编号。
- 拖动提问侧栏左边界调宽，记住上次宽度；小窗口改为覆盖显示。拖柄可用方向键调整，双击恢复默认。
- 打开提问侧栏时，顶栏与剩余画布一起收缩；用户消息靠右、回答靠左。标题栏和节点信息采用紧凑布局。
- 图片/PDF节点提问自动附带文件，附件设置区已移除。PDF默认读取全部页面；在问题中写“只看第2–4页”可指定范围，“第五题”不会当作页码。前后端不再限制最多6页。
- 桌面提问侧栏顶部与顶栏顶部对齐，利用原先空白处。每次提问入口下方附带可折叠学习清单：阅览、提炼、亲笔推导、对比权威答案；手动勾选，随导图保存。生成完成不自动标记学完，Markdown导出保留复选状态。
- 撤下 GLM-image 生图入口及接口。已有图片、图片/PDF提问和各服务商的本机密钥保留。
- 停止或传输失败时保留已完成节点；正常情况下每次生成可一步撤销。期间的其他编辑按正常操作顺序撤销，不会重新出现半截生成结果。
- 保留非画布防误缩放、单行公式分步推导、PDF内部标题栏。公式正文按完整节点渲染，尊重减少动画设置。

升级后重启8794服务，并按 Ctrl＋Shift＋R 刷新。详情见 [更新记录](FEATURE-NOTES.md)。

## 知识单元与自由关系（2026-10-22）

文字、PDF整理和节点提问优先让一个节点讲清一个完整知识单元，定义、条件、性质和连续推导在节点内部组织。关系使用粗分类与自由文字标签，可表达等价、特例、反例等，显然的层级可留空标签。旧关系类型继续兼容，已保存导图不会自动改变。规则与格式见[提示词维护](docs/prompt-investigation.md)。

## 数学review与出处修复（2026-10-22）

拖动不再重复创建“出处”按钮，标签保持单行。生成内容会本地检查上下标、LaTeX及公式定界；只对存疑批次额外调用当前模型复核，保留明确的行内/独立排版。复核仅允许补充定界符，不改数学内容；失败或不确定显示“公式待检查”，具体过程可调查。新增prompts/math-review.md，现有历史节点不自动改写。

已有文字节点：右键 → “检查数学排版”，先查看修改前后，再“应用修改”；支持一步撤销，保留节点身份、坐标、连线和出处。如果预览后节点又被编辑、删除或切换导图，拒绝应用旧结果。复核过程单独存为当前导图的生成记录。图片/PDF文件节点不提供此正文检查入口。

## 主题团块、自动整理与连线（2026-10-22）

- 新的AI生成结果按实际主题划分团块，主题之间使用不同的柔和色相；团块内部按包含层级调整底色深浅，连续推导不因步骤数而逐级变色。总览和原PDF置于内容团块旁。
- 流式生成时节点继续逐个出现，完成后只整理本轮新节点一次。原有节点不移动；生成中手动移动过的节点和手动改过的颜色保留。整理不会改写正文、数学公式、出处或连线含义，也不额外调用模型。
- 顶部“自动整理”旁选择“当前分支”或“整张导图”；当前分支从选中节点沿主干/层级延伸，明确的对比、并列和跨主题关联不作为分支延伸。Ctrl+Z一步撤销整理，重做可恢复。
- 旧导图打开时不自动重排；点击“自动整理”按已有分支分组。旧图没有主题标记时，程序不会猜测语义或补发模型请求。
- 新导图默认使用曲线。顶部“连线”可切换曲线、折线或直线；实际选中一条连线时只改该线，可用“跟随导图”取消单独设置。旧图保留已存的默认样式。
- 选中节点会强调直接相接的线、箭头及关系标签，多选时取这些连接的并集；不会继续向外扩散。高亮不等于选中连线，删除和样式操作仍按真正选中的对象执行。

## 树形结构与简明概览（2026-10-22）

- 顶部新增“详细 / 概览”切换。概览以总览和主题短说明呈现结构，减少公式；点击某个主题进入相应详细分支，点击中心查看完整导图。手机端为可滚动的文字卡片。
- 新的AI生成在同一次回答中同时给出详细正文和简明概述，不为概览额外调用一次模型。概览由已有主题关系及概述组织，不会创建第二份导图或往画布塞入重复节点。旧图缺少概述时，根据现有主题与标题生成结构概览；不重新发送资料。
- 概览用于阅读与定位；编辑、拖动及连线设置请切回“详细”。切换不改变详细节点的位置、内容或出处，不新增撤销步骤。
- 自动整理改为中心附近的主题子树左右展开，按实际子树高度分配空间；同级节点分开摆放，内部连线接点随方向分散，减少共用同一通道。PDF和文件说明位于知识树外侧的资料区，不用其尺寸决定左右分支空间。
- 去掉上一版淡色主题背景框及装饰标题。继续以节点色相区分主题、底色深浅表达包含层级；重复整理沿用已分配的主题色。跨主题关联默认较淡，选中相关节点或连线时强调。
- 新生成完成时整理本轮内容；旧图可点击“自动整理”试用新布局，Ctrl+Z一步恢复。整理调整位置和本轮内部连接的接点，不合并或删除正文节点，不改变连线方向、含义和出处，外部母链接点保留。

## 完成后清理占位与真实分组底框（2026-10-22）

- 课件生成有可用知识内容后，自动移除“正在逐页整理”和“共若干页，处理范围见生成过程”两类过程占位节点，修复原有分支连接。PDF阅读节点、知识正文、出处与生成记录保留。用户已经改写为实际内容的占位节点保留；整轮撤销仍有效。
- 已保存的旧导图：打开后点击“自动整理 → 整张导图”，可一起清理这些旧占位节点、整理知识树并生成主题底框，支持Ctrl+Z一步恢复。更新程序不会直接改写个人导图文件。
- 主题标记复用现有空间分组底框：拖动标签移动整组，双击标签改名，右键调整颜色、底色浓度和边框，删除底框保留内容节点。重复整理复用原框，保留改过的名称和样式；远处展开的章节使用独立底框，避免把中间无关内容圈进来。

## 整图结构复核（2026-10-22）

AI文字、课件生成完毕后，使用当前模型复核全讲结构：参照目录合并零散/同义主题，整理“中心→主模块→子主题”，然后让概览和详细导图共用该结构。保留原节点、正文、公式与出处；只调整归属、层级、布局与主题色。通常额外一次调用，超过100个节点时分层复核；失败保留原结构并说明原因。

已有导图可点工具栏“结构复核”，先预览再应用，支持一步撤销；“自动整理”继续是纯本地布局操作。提示词位于 `prompts/structure-review.md`，实际输入/输出/理由可在“提示词与过程”查看。完整环节见[生成流程](docs/generation-workflow.md)。

## 模块归并、顺序编号与讲义学习清单（2026-10-22）

整图结构复核先检查同义重复、同板块碎分和层级尺度混杂，再参考目录与知识联系给出模块学习顺序。程序按复核后的数组显示01、02等编号；概览和详细图先排左侧从上到下，再排右侧从上到下，大节点不再打乱顺序。编号不写入原正文。已有导图需主动“结构复核”后采用新的逻辑顺序。

详细画布的模块节点旁及概览中，每个已复核的二级模块带默认展开的五步学习清单：通览结构、精读提炼、串联关系、主动复现、应用自检；中心汇总整讲进度。由用户勾选，与解题链四步清单分别保存。具体含义见[使用指南](使用指南.md)。

## 详细画布学习清单与双视图联动（2026-10-22）

五步清单直接附在详细画布的二级模块代表节点旁，默认展开，随节点拖动；布局预留展开空间，旧图显示时避开正文和出处，不自动改动已有坐标。详细与概览共用勾选、展开状态及整讲汇总。清单“概览 ↗”定位对应模块；从详细选中节点切到概览会标出对应模块/子主题，点击概览返回详细分支。单纯切换视图保留详细画布视角。


### 导图引用与多图总结

首页支持多选 2–8 张已保存导图，复用当前 AI 配置生成有节点来源的新总结图。画布操作栏与空白处右键支持插入带布局预览的跨导图引用卡片，可跳转并返回原位置。详见 [使用说明](docs/map-references-and-summary.md)。

### 导图库与双画布

左侧支持文件夹、搜索、多选和直接切换导图。将列表中的导图拖到画布，可在落点插入引用卡片；双击卡片跳转，右键“分屏打开”进行双画布对照。两侧独立编辑保存，同一张图只打开一份。详见 [导图库与双画布说明](docs/map-workspace.md)。
