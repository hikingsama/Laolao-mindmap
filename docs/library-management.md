# 导图库与回收站管理

主界面“我的导图”提供文件夹路径、新建文件夹、回收站和“多选管理”。全部导图展示全库导图及顶层文件夹；进入文件夹后展示直属导图与子文件夹。文件夹数量包含其后代中的导图。“未分类”展示没有归类的导图。

## 文件夹与导图的共同选择

主界面、侧边栏与分屏画布共用选择状态。选择可跨目录与搜索保留，底栏同时显示去重后的导图数与文件夹数。选中文件夹会递归选择其全部子文件夹、空文件夹及导图，包含折叠或搜索隐藏的内容。取消一个子项后，相关祖先变为“部分选中”（−）；它们不属于完整选中的文件夹，删除时会保留这些祖先，只处理仍选中的内容。子项全部选中时祖先恢复全选状态。空文件夹可独立选择。

首页的文件夹勾选框用于选择，文件夹名称用于进入目录，方便进入后取消具体子项。侧边栏多选时点击文件夹行或勾选框选择，展开箭头仍用于查看子内容。

“全选可见内容”选择当前显示的文件夹与导图；选中文件夹仍包含所有后代。只有导图时显示“全选可见导图”。侧边栏全选以实际显示行作为起点，选中文件夹时包含折叠内容。全选后变为“取消全选”，清除所有位置的选择，不另设清空按钮。操作数量不限8张；多图总结仍限2–8张，且不能混选文件夹。

## 移动与删除

批量移动可混选文件夹与导图，只移动完整选中的最高层文件夹和未被它们包含的导图，内部层级保持不变。目标列表排除所选文件夹及其后代，服务端也校验循环、同层同名与最多16级层级。移动到顶层时，单独的导图进入未分类。

文件夹菜单只有“文件夹及内容移入回收站”，已移除“删除文件夹但保留内容”。旧页面发送原 `deleteFolder` 操作会被拒绝，须刷新。确认对话框显示实际包含的全部文件夹和导图数量，并说明隐藏子内容、草稿、图片及PDF会一起回收且可恢复。确认期间目录或保存版本变化会拒绝整批删除，不按过期清单猜测。

完整文件夹作为一个回收项目保存完整树、归类和所有导图文件目录；单独导图作为独立项目。未完整选中的父文件夹继续保留。成功删除的导图会退出已打开画布，避免自动保存使它重新出现；未保存草稿随原目录保留。

## 回收站

支持按名称、原位置及整组内容搜索，按删除时间从新到旧排列。每项显示名称、删除时间、原位置；文件夹项目还显示文件夹数、导图数和内容列表。可单项或批量恢复、彻底删除，可全选当前可见项目／取消全选。回收站使用独立选择，不污染正常导图库的多选状态。

恢复保留导图编号、正文、草稿、附件、引用目标及目录层级。原父级不存在时恢复到顶层／未分类并提示；同层同名文件夹添加“恢复”序号，不合并原有树。同编号冲突时整组恢复失败，保留原回收记录。批量操作只清除成功项，失败项继续勾选并显示原因。历史版本的单导图回收记录兼容恢复与彻底删除。

“彻底删除所选”仅处理所选项目；“清空整个回收站”单独显示，明确包含当前搜索未显示的项目。两者均再次确认数量、附件和不可恢复性。请求携带确认时的具体记录与版本，不会连带删除之后新增的回收项目。

若系统权限或磁盘错误导致彻底删除中途失败，会保留私有清理记录，界面继续显示失败项并支持重试。这时部分文件可能已经删除，不能再恢复；界面会明确标注。链接检查等删除前校验失败不进入这一状态。

## 本地存储与部署

文件夹归类位于 `storage/maps/.library.json`，回收项目位于 `.trash/`。新记录私有 `.trash-info.json` 版本2；导图目录在项目的 `maps/<原导图ID>/` 下，正文、媒体及草稿文件均完整保留。原文件不会被重写或摘要化。

整组删除／恢复通过私有 `.library-transaction.json` 记录文件移动和归类快照。操作异常回滚，服务中断后的未提交事务在下次资料接口访问时回滚，已提交事务完成收尾。归类版本、导图保存版本、回收记录版本均校验；不覆盖编号冲突。递归清理前验证绝对目标位于回收目录内并拒绝链接目录和文件。

彻底删除开始前另在 `.trash/.purge-<回收编号>.json` 保存收尾信息，清理成功后移除。删除中途服务退出或文件权限异常时，这份记录保证条目可见、能够重试清理。

这是本机单进程服务的文件事务。上线多进程或多用户服务器前，仍须实现用户权限隔离、数据库／进程间事务锁与共享存储协调，参见 [服务器部署待办](server-deployment-handoff.md)。

更新后重启本地服务并 Ctrl+Shift+R 强制刷新，前后端一起更新。

## 验证

- `node tools/verify-folder-trash.cjs`：父子勾选、去重、移动限制、版本冲突、整组回收／恢复、空文件夹、旧记录兼容、恢复冲突、故障回滚、中断恢复及链接路径保护。
- `node tools/verify-folder-trash-ui.cjs`：Playwright + Edge 验证主界面与侧栏同步、混选移动、部分删除、搜索、批量恢复、失败保留勾选、彻底删除与清空确认、窄屏布局。
- `node tools/verify-home-library.cjs`、`node tools/verify-workspace.cjs`、`node tools/verify-map-library.cjs`：主页、双画布、草稿、引用和总结回归。

测试全部使用临时资料、独立端口及假模型，不访问个人导图或真实API密钥。
