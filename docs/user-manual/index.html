01 开始使用

  1. 双击项目文件夹中的 启动服务.cmd，保持服务窗口开启，打开 http://127.0.0.1:8794/。首次使用需 Node.js 18 或以上，无需另装项目依赖。
  2. 点击“新建空白导图”，或在“我的导图”中搜索、打开卡片。卡片三点菜单可改名、复制或删除。
  3. 在画布记录内容、连接关系；修改后按 Ctrl + S 正式保存。

已有笔记可用“粘贴文字生成”或导入 JSON / Markdown / TXT。粘贴文字当前按本地规则拆分，不调用 AI 理解。

02 自由画布与附件

双击空白新建文字节点。
双击节点编辑正文；支持 Markdown 与 LaTeX 公式，并可预览。
拖动 / 连线拖动节点移动；从四边中点拖出连线。
多选Ctrl + 点击多选；空白处右键拖动扫选。
移动 / 缩放空白处左键拖动画布；Ctrl + 滚轮缩放。
右键节点调整颜色、字号、样式、分组；也可进入节点提问。
底部线标画直线、方框、圆框，并调整颜色和粗细。

图片与 PDF

拖入文件，或点击“插入图片 / 插入PDF”。“媒体文件”可管理和复用附件。

拖动 PDF 顶部标题栏移动节点，右键操作，双击文件名重命名；正文区域可悬浮阅读、选字、滚动和翻页。

附件节点提问自动带上文件；PDF 默认读取全部页面。只需部分页面时，直接写“只看第2-4页”。

文字与公式

文字节点支持 Markdown、任务复选框和 LaTeX。说明与主要公式分段，每一步公式单独成行，便于阅读和推导。

03 围绕节点提问

配置一次

顶部“大模型 API 接入”支持 DeepSeek、智谱 GLM、Kimi 和自定义兼容服务。填写服务商、接口地址、API Key、准确的模型名称，点击“测试连接”后保存。地址末尾不必加 /chat/completions。

发送与展开

右键节点选择“提问”。发送后，完整知识点直接逐步生成到画布，无需手动整理或推送；每次提问单独形成一组。

方向、范围与追问

展开“回答方向与参考范围”，指定解释方式或参考范围。同一树内可以换节点继续追问；系统沿当前推导路径参考历史，相关树作为有出处的资料候选。

子链用不同颜色区分；点击入口“查看过程”可查看方向、引用来源与正文快照。完成后的节点可双击编辑。

停止与中断

点击“停止”保留已完成节点。关闭侧栏会继续生成；保存、撤销或切换导图 / 提问节点会停止当前生成。通常一整组生成可一步撤销。

图片 / PDF 提问需视觉模型，附件会发送给已配置的平台。PDF 默认整份读取，“第五题”按题号理解，明确写“第2页”才限定页码。正常提问先关联资料、再生成回答，通常包含两次模型请求。

截图为演示内容；实际地址、密钥与模型名称请按服务商提供的信息填写。

04 学习、保存与导出

四项依次为：阅览、提炼、亲笔推导、对比权威答案。

用鼠标勾选，或聚焦复选框后按空格；可折叠或取消勾选。全部完成显示“本轮学习完成”，AI 生成完成不会自动勾选。清单跟随入口移动，勾选和折叠状态随导图保存。

Ctrl + S正式保存，继续编辑。
保存并退出保存当前修改后，回到学习书桌。
不保存退出确认后放弃上次正式保存之后的修改。
PNG导出画布图片，便于展示或分享。
Markdown导出笔记正文，保留学习清单的勾选状态。
JSON导出导图结构、问答历史和学习记录，便于备份与再次导入。

自动保存的是恢复草稿。希望留下正式版本时，请按 Ctrl + S。含图片 / PDF 的项目建议整体备份项目内的 storage 文件夹；JSON 只保留附件引用，未内嵌附件文件本体。

遇到问题时

  • 模型未接入：检查本地服务、API 配置和连接测试。
  • 生成中断：展开“查看过程”查看原因；已完成的节点可作为继续提问的起点。
  • 更新后界面没变化：按 Ctrl + Shift + R 强制刷新。
