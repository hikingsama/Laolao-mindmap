# 导图引用与多图总结

## 引用另一张导图

打开画布，点击操作栏的“引用导图”，或在画布空白处右键，选择“引用其他导图”。搜索后选择目标导图，再点击画布确定位置，会插入一张包含名称和布局预览的卡片。也可从左侧导图库拖入，在松手处生成引用。

卡片和普通节点一样可以移动、缩放、删除和撤销。双击卡片跳转；右键可选择“分屏打开”。画布标题栏的“←”可返回上一张导图，恢复原来的草稿、选中节点与画布位置。卡片绑定导图编号，改名后仍能找到原图。保存目标图或重新切回窗口后，预览和名称会更新。

目标被移走或删除后，卡片保留并显示“重新关联”，可以重新选择已有导图。引用卡片不会复制目标图的全部内容，也不会自动展开成另一棵树。

## 多张导图生成总结

在左侧导图库点击“多选”，或在“我的导图”中点击“多选导图”，选择 **2–8 张**，点击“多图总结”。可以选择：

- **逐图回顾**：保留各张导图的主要知识。
- **按主题融合**：归并共同概念，串联前提、递进和应用。
- **比较异同**：整理共同点、差异、适用范围与资料中的冲突。

再选择“简明概览”或“标准总结”，填写可选的补充要求。直接复用顶部“大模型 API 接入”的当前配置。

本次读取的是每张导图的**正式保存版本**。有未保存草稿会在开始前提示；需要包括最新改动时，先返回原图保存。支持总结文字节点，图片、PDF和其他导图的引用卡片需先整理成文字节点。一次最多处理30万字符；较长内容会分批处理并多次调用当前模型。

生成流程为：锁定来源版本 → 逐图分批梳理 → 跨图归并 → 校验来源编号 → 检查数学排版 → 复核模块、层级与顺序 → 整理布局并保存新图。

新图保留每个知识节点的“来源”入口，可定位到原导图的原节点；画布中也放置原图的引用卡片。原图的正式内容不受影响。

点击“停止”会终止后续调用，将已完成的逐图内容保留在新图草稿及“总结来源”的生成过程中。部分结果的画布展示有数量上限，完整已完成批次仍保留在生成记录；未完成结果需要手动正式保存。切图、撤销或退出会停止生成，避免重新插入用户刚撤销的内容。

## 来源更新

生成结果保存来源版本。原图后来正式保存了修改，操作栏和“来源”入口会显示“已更新”。结果不会自动重写。点击“重新总结为新图”，确认选项后使用最新正式版本再生成一张新图，旧总结仍保留。

来源节点被删除时，会打开所属导图并提示原节点已经移除；来源导图被删除时会保留引用和失效提示。

## 人工检查提示词与过程

“多图总结”窗口可打开现有的提示词检查入口；生成后可从“总结来源 → 生成过程与提示词”查看具体过程。核心模板位于 `prompts/map-summary.md`，结构与数学检查复用 `prompts/structure-review.md`、`prompts/math-review.md`。目前模板入口只读；开发者可以编辑这些本地文件。

## 本地验证

运行 `node tools/verify-map-library.cjs`，使用临时资料与模拟流式模型检查后端，不读取个人导图或真实密钥。设置 `MM_TEST_JSDOM` 为已安装的 jsdom 包路径后，还会运行实际网页脚本的界面交互检查。应用运行无需安装新依赖。
