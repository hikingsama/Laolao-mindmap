## 2. 当前功能列表

### 2.1 节点、选择与复制

- 双击空白画布创建空白文字节点，没有“中心主题”“分支主题”等默认正文。
- 单击节点只选中；双击文字节点才编辑。选中后直接打字、F2、Enter 不启动文本编辑。
- 左键拖动节点；四边和四角调整尺寸。靠近磁吸点时优先显示连线用的可点击光标，其余边缘用于缩放。
- 自动尺寸按内容计算；手动尺寸分轴管理：只改宽度则宽度固定、高度继续自动适配；只改高度反之；两者固定后溢出内容内部滚动。右键可恢复内容自适应。
- 正文默认正常字重、16px，按实际节点宽度换行；Markdown 标题与显式加粗另行表达。
- Ctrl/Cmd 点选可追加或取消选择；多选后整体拖动、批量改颜色/标记/进度/字号或删除。
- 空白处按住右键拖出淡色矩形扫选；与节点接触即选中，Ctrl/Cmd 可追加。扫选不会自动成组；画布禁用网页右键菜单。
- Ctrl+C/X/V 支持单节点、多选节点、底框及其完整包含的内容。多节点副本保留相对位置和内部连线，包括箭头方向、标签、自环；不复制连向未选节点的外部边。
- 复制底框时带上内部节点、内层底框和内部连线，不带线标；空底框也可复制。
- 普通多行文本粘贴为一个节点；显式“粘贴文字”入口可按标题/列表解析拆点。
- 支持撤销、重做；一次批量操作或整份粘贴一般只占一步撤销。

### 2.2 连线与箭头

- 节点四边中点各有一个磁吸点；在两个磁吸点之间拖动建立连线。
- 从磁吸点拖到空白处松手，会创建新空节点，并建立指向新节点的箭头。
- 两端磁吸点固定，不随节点相对位置自动切换。移动、改尺寸后重新计算直角折线路径，绕开两端节点。
- 同一个节点的不同磁吸点可以相连，表示自环；同一磁吸点不能回连自身。
- 拖线时，靠近其他节点边界会显示目标节点的四个磁吸点，接近具体点才吸附。
- 连线可单击选中、Delete 删除；右键可设置无箭头、正向、反向、双向或删除。
- 右键可添加连线文字标记，显示在路径中间的直角小方框中；双击标记修改，清空文字删除标记。
- 暂无连线多选、批量操作或手动拖动折点；用户认为暂时不需要连线多选。

### 2.3 分组底框

- 一个或多个节点右键“添加到新组”，生成位于节点与连线下方的淡色底框。
- 标签位于左上框外；点击标签选中底框，拖动标签移动，双击标签改组名，右键修改颜色、边框粗细、底色浓度或删除。
- 底框本体不能嵌入正文，内部点击穿透；通过标签选中。边缘/角调整柄始终可用，无需先选中。
- 完全包住的节点和内层底框才算被包含；支持嵌套。部分相交、等大重合不形成包含关系。
- 选中底框不会顺带选中节点；拖动底框会带动拖动开始时完全包含的节点和内框，各移动一次。途中经过的对象不被吸入。
- 调整底框大小不移动或缩放内部节点；删除底框不删除内部节点或内框。

### 2.4 节点之间的视觉对齐

- 拖动节点或多选节点时，显示紫色辅助线并轻微吸附；多选按整体外框计算，相对位置不变。
- 吸附距离为约 6 个屏幕像素，不随缩放改变；Alt 临时关闭吸附。
- 至少两个节点时，右键“排齐节点”支持左、水平居中、右、顶部、垂直居中、底部对齐。
- 至少三个节点时，支持横向/纵向等间距，以边缘间距计算，保留排列两端位置；一次撤销恢复全部。

### 2.5 Markdown、LaTeX 与文字工具条

- 双击文字节点，源码编辑器与实时预览并排显示；窄屏上下排列。
- Markdown 支持标题、加粗、斜体、删除线、引用、列表、任务列表、表格、链接、行内代码和代码块。
- KaTeX 渲染数学公式：`$...$`、`\(...\)`、`$$...$$`、`\[...\]`；美元符号内侧带空格也可识别。支持矩阵、aligned、cases 等常用数学环境。
- 当前工具条只保留：**字号、B 加粗、I 斜体、黄色荧光笔**。字号 10–48，作用于整个文字节点；右键“正文样式”只保留字号，支持多选批量设置。
- 加粗 `**文字**`、斜体 `*文字*` 是标准 Markdown；高亮 `==文字==` 是项目额外支持的扩展。按钮修改 Markdown 源码，没有另一份富文本数据。
- 多段选区格式操作尽量保留标题和列表前缀；公式、代码区域内不插入文字格式。
- 手写的任务复选框可在正文或预览中直接勾选，并写回 `- [ ]` / `- [x]` 源码；正文勾选可撤销。
- Enter 换行，Ctrl/Cmd+Enter 保存本次编辑，Esc 取消；文字和待提交字号一起保存或取消。
- LaTeX 补全主要覆盖中国大陆 STEM 大一高等数学、线性代数，包括分式、极限、微积分、级数、矩阵/增广矩阵、行列式、向量、特殊符号等。实际命令清单以 `MMCompletion.definitions` 与右上角“补全快捷键”表为准，参考栏可搜索。
- 只有在数学区域内按 Tab 才展开已知模板；模板分多个具名填空区。Tab 下一项、Shift+Tab 上一项，支持嵌套补全。积分有上下限、被积函数、微分变量；极限有变量、趋近点和函数。

### 2.6 画布与线标

- 空白处左键拖动平移，滚轮/触摸板支持横向、纵向平移。
- Ctrl/Cmd+滚轮及 Ctrl/Cmd+`=`/`-` 缩放，范围约 15%–300%，左下角显示比例。
- 一次连续滚动锁定起始区域：从画布开始就持续平移；从溢出节点、编辑框、预览或 PDF 开始就持续内部滚动。跨入其他对象、到达内容边界都不接力切换；停顿约 220ms 或点按后重新判断。
- 绘图标记现统一叫“线标”：直线、方框、圆框；颜色、粗细可改，位于节点和连线之上。
- 线标可选中、拖动、删除、撤销；周围约 12 个屏幕像素可命中。覆盖节点时，右键优先打开线标自己的菜单。
- 线标颜色在悬停子菜单修改，粗细在右键菜单中直接输入，不使用右侧样式栏。

### 2.7 图片、PDF 与媒体文件管理

- 支持选择、拖放、粘贴图片或 PDF；图片支持 PNG/JPEG/GIF/WebP，单文件 20MB；PDF 50MB。
- 图片/PDF 是可移动、改尺寸、连线的媒体节点；文件标签位于左上框外，有与节点边框一致的底色。
- 图片默认名为“图片yymmddhhmmss”加真实后缀，重名自动加序号；PDF 保留原文件名。
- 左侧媒体栏只显示当前导图文件：同一文件只列一项，显示使用 N 处或未放置，可再次插入、定位、改名、删除。
- 多位置文件可展开具体位置；删除节点保留文件，删除媒体文件移除其所有画布实例，可撤销。
- 跨导图粘贴会复制实际媒体文件，目标副本不依赖源导图。
- **双击图片/PDF 的框外标签改名**；媒体节点/标签右键也有“重命名文件”，与媒体栏改名共用一个窗口。
- 改名只编辑主名，后缀单独只读；同名不覆盖，非法名称留在窗口提示修正；同文件所有标签和媒体列表同步，不改变节点编号、位置、尺寸或连线。
- 改名先进入草稿，正式保存才改实际文件名；不保存退出恢复原名。

### 2.8 PDF 阅读

- 本地 PDF.js 6.4.299 阅览组件，Apache-2.0，资源随项目提供，无 CDN 或额外服务进程。
- 默认适应节点宽度，纵向连续排页；节点足够高时能同时显示多页，不能退回旧的单页预览。
- 悬浮约 160ms 即可滚动和操作；不改变当前节点选择、键盘焦点、画布位置，不自动弹出放大窗口。
- 离开约 280ms 后停止交互，但保留刚才可见的文档区域及页内偏移；再悬浮、保存重开都从原位置继续。选择文字、输入搜索或连续滚动时不自动结束。
- 节点宽度改变时重新适宽，保留页内阅读比例。手动 PDF 缩放独立于画布缩放，“适宽”可恢复默认。
- 支持文字选择复制、页码跳转、翻页、正文搜索、高亮匹配、放大阅读、Esc 退出；20% 总览不自动激活阅读器。
- 每次只有一个完整阅览器；未交互位置保留连续可见区域的栅格预览，最多约 4MP，只画需要的页面片段。
- PNG 导出包含当前可见的连续区域，移除阅读工具栏。
- 暂无 OCR、PDF 批注编辑、加密文档解锁。

### 2.9 保存、退出与导出

- 正式文件在 `storage/maps/<导图ID>/map.json`，媒体文件与它在同一导图文件夹；没有云同步。
- 自动保存用于恢复草稿，写 `.draft/`，另有浏览器 localStorage 恢复副本，不提前覆盖正式文件。
- Ctrl/Cmd+S 正式保存并继续编辑；标题旁“保存并退出”“不保存退出”都需确认。
- 不保存退出回到最近一次明确保存的版本，包括媒体改名、删除、新增等操作。
- **已保存且没有新草稿时，再次保存算成功；保存并退出确认后正常退出，不报“没有可保存的草稿”。**
- 保存失败保留当前页面和草稿；令牌检查防止旧请求覆盖，正式文件 hash 检查外部冲突，提交日志与备份支持中断回滚。
- 刷新或意外中断后，重开可选择恢复草稿、放弃草稿、取消打开。
- 支持本地导图列表、JSON 导入/备份，Markdown/TXT 文字导出、PNG 画布导出。JSON 不包含媒体二进制，迁移应复制整个导图文件夹。

## 4. 数据约定

保持现有格式兼容，不把节点几何坐标塞进节点本身：

```js
map.nodes = [{ id, text, children: [], color?, bold?, marks?, progress?, fontSize?, image?, pdf? }];
map.pos = { [nodeId]: { x, y } };       // 节点左上角，画布坐标
map.size = { [nodeId]: { w, h } };
map.sizing = { [nodeId]: { w: true, h: true } }; // 手动固定的轴；其余自动
map.edges = [{ id, from: { node, side }, to: { node, side }, dir, label? }];
// side: n/e/s/w；dir: none/fwd/rev/both
map.groups = [{ id, title, x, y, w, h, color, opacity, width }];
map.annotations = [{ id, type, x1, y1, x2, y2, color, width }];
map.media = [ /* 媒体编号、文件名、MIME、来源等元信息 */ ];
map.pdfViews = { [nodeId]: { page, scale, top?, left?, offset? } };
```

上述为结构示意，问号表示可选字段。分组包含关系按空间几何实时判断，不在节点上存父组。`pdfViews.offset` 是当前页的页内比例，用于适宽后恢复；兼容旧绝对 top/left。新增与节点编号相关的映射表时，应同步检查 `LAYER_MAPS/LAYER_LISTS`、复制、撤销、导入和删除清理。

## 7. 已知边界与下一会话工作方式

- 连线路由主要保证绕开两端节点，尚不保证避开任意第三节点或其他边；端点被重叠节点挡住时仍需调整位置。
- 暂无自动整理整张画布、云同步、多人实时协作、OCR、PDF 批注和真实模型接入。
- 旧 README/HANDOFF/BRIEF 含有第一版树结构、缩放柄、单页 PDF、正文对齐等历史内容。请以本文件、最新用户指令、实际代码为准，不要照旧文恢复已删除功能。
- 用户没有软工背景，偏好清楚、具体的解释。API 接入需要逐步教学；已授权的常规功能修改则应落实完成，不反复询问确认。
- 用户希望新会话降低无效耗时：先读此文件，再按需求定位相关文件；不必重新遍历整个项目、重做旧功能或每次跑全部测试。小改动选相关验证，出现新问题再扩大范围。
- 用户数据和密钥不用于验收、不写入输出或提交；`.env*`、`*.local`、`storage/` 已忽略。不要读取密钥来证明模型已接入；当前 AI 后端是否占位从公开服务代码即可判断。
- 本轮最后一次代码修改已完成，没有正在执行的实现任务；等待用户下一项需求。最新服务端修复是否已在用户的 8792 进程中生效，需看用户是否已按提示重启，不能假定已重启。
