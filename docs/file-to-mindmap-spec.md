# 课件与讲义生成导图

更新：2026-10-21。PDF与多讲义首版已实现。入口：“大纲 / 正文生成导图 → 上传课件 / 讲义”。PPT/PPTX请先导出PDF。

## 使用流程

1. 一次选择一份或多份PDF，每份最多50MB；显示页数，可调整顺序或移除。
2. 逐份选择“嵌入到导图”（默认勾选），可批量选择。不勾选仍解析，保留文件名与页码，不保存原文件附件。
3. 默认“按讲义分支”；“跨讲义主题融合”先提炼全部资料，再分级汇总共同主题。详细章节保留在生成记录，可直接展开，不再次调用模型。
4. 自动识别文字与图像、每页图文理解、仅提取文字三种读取方式。前两种可能发送页图，需要视觉模型；仅文字遇到扫描页明确失败，不静默跳过。
5. 复用唯一API配置，按页段分批调用，显示文件与阶段进度。主题融合另有汇总调用。

## 处理边界

- 从第一页到末页读取，没有隐藏的前6页限制。每批最多4个文字页段或3张页图；长页拆分，全部分段完成才标记该页完成。
- 每次请求最多40个知识节点，按讲义分支可累计超过40个。融合保留提炼结果，再以摘要分级归并，概览不替代章节记录。
- 来源使用独立文档ID与页码，同名文件不会混淆。节点“出处”可跳到已嵌入PDF对应页；未嵌入则明确仅有出处信息。
- 默认依据原文，允许补充时单独标明。程序校验输出节点、连线、来源及结构；模型不得引用未提供的页。
- 完整节点流式进入主画布，可停止；单文件失败保留其他文件结果，记录未完成范围。切换导图取消任务，防止串图。
- 本轮知识节点与新增PDF共用一个撤销批次，原始记录保留；保存重开仍可调查。
- 现有单图JSON保存上限512 MiB；接近480 MiB时停止新调用并提示拆图，避免继续消耗。这是保存体积限制，不是文件页数截取。
- PDF保存为附件及可阅读节点，不将二进制写进JSON。单独JSON不携带原PDF，完整迁移需保留storage中的附件。

## 提示词与调查

九份模板集中在prompts目录，实际调用的系统提示词、版本、文字输入、输出保存在生成记录。顶栏“提示词与过程”只读查看；进度面板“查看生成过程”直达本轮记录。

不保存密钥、页图编码或思考正文。用户自定义编辑界面留待后续。详见[prompt-investigation.md](prompt-investigation.md)。

## 节点粒度更新（2026-10-22）

课件提炼与主题融合优先生成完整知识单元，不将一句性质或一个运算单独拆成节点。定义、条件、性质和简短例子在同一节点组织，连续推导保留分行独立公式。连线使用粗分类kind与自由label，支持学科自己的关系措辞；明显层级可以不显示标签。仍按提供页分批处理，不自动改写旧结果。

## 全轮结构复核

各页段提炼与可选主题融合完成后，汇总本轮节点标题、简述、父级及目录线索，使用当前模型统一全讲模块/子主题与原节点归属。程序检查完整覆盖，保留正文、公式、出处与所有知识节点，只重建包含树；失败保留原结构。概览和详细布局共享审核后的结构。通常额外一次调用，超过100节点时分层。详细环节见[generation-workflow.md](generation-workflow.md)。
