# 大纲、正文与图片理解生成导图

文字入口现已统一为AI理解生成，不再提供“按原大纲本地解析”选项。历史本地生成记录以及导入大纲所需的格式解析仍兼容。

## 使用入口

在“大纲／正文生成导图”的“内容来源”选择：

- 粘贴文本：直接保留完整输入，以AI通读规划生成大纲，再按语义单元整理导图。
- AI识别图片：按选择顺序上传PNG、JPEG或WebP，先识别完整正文，再全文规划。每次最多8张，每张20MiB，合计80MiB。需要支持视觉输入的模型。
- 按主题编写学习稿：输入主题与学习目标，AI根据全局学习背景编写连贯学习稿，再规划生成。识别稿、导图总览与后续提问依据均保留“AI编写”标记，不冒充用户原始讲义或已通过知识审查的材料。
- 上传课件／讲义PDF：复用现有PDF后台通览、主题规划、原页回读与生成流程，保留页码出处。

文字／识别正文总量最多200000字符，主题输入最多3000字符。应用上限不代表模型平台上下文能力；超限明确报错，不静默裁掉尾部。长材料应按完整主题调整范围。

## 完整理解、规划与复核

粘贴文字保留原样，不额外请求模型把完整正文改写成短摘要。图片识别精确覆盖全部原图，保存识别疑点，并按用户选择顺序恢复来源；原始图片永久保留在任务资料中直到用户主动清理。按主题拟稿与原件识别使用不同提示规则。

全文规划读取全部正文片段，确定主题、完整知识单元、范围、阅读顺序和依赖。片段仅提供稳定定位，不决定节点切分；保护数学、代码等结构，片段合并也不删除文字。规划必须恰好覆盖所有原文片段，缺段、重复分配、未知来源、循环或向后依赖均拒绝后续生成。每个语义单元生成时读取完整关联原文与直接依赖单元的完整正文；图片任务同时实际附带相关原图，用户改写识别正文后则每个单元回读全部原图，避免编辑导致映射失效。

每单元1–40个文字节点，上限不是目标。生成后复用数学排版检查、独立节点内分节复核，最后进行整图结构复核；这些步骤不等于独立知识正确性或OCR完整性审查。分节复核仅插入标题，不能重写正文和公式。

## 可选查看与修改

默认一键后台完成。勾选“先查看、修改识别正文与全文规划”后，完成识别及规划就进入“等待核对”，不会先生成节点。

从顶栏“后台任务”点击“查看／修改正文与规划”。可以修改完整正文、单元标题、主题及整理范围，查看来源段落、前置单元与原图。正文变化会建立新修订并重新规划，再等待查看；只调整规划标题、主题或范围则校验覆盖及依赖后直接继续。原始输入、首次识别稿与修改历史独立保留。编辑请求带修订号，旧窗口不能覆盖新稿。当前UI不提供手动重排依赖或拖动单元；服务端仍严格校验完整计划。

## 后台与结果领取

与PDF讲义共用同一任务列表、串行队列和本机进程锁。上传完成并提交后，可以关闭整个浏览器；本地服务、电脑与网络需保持运行。关闭网页或切换导图不会取消已提交任务。等待核对的任务也会独立保存。

支持停止、继续未完成阶段、服务重启后恢复；已完成模型阶段复用，不自动重发完成状态不明的请求。此类请求仍需用户明确确认可能再次计费。任务保存提交时的学习背景、模型和接口地址，密钥不落盘。

完成结果独立保存，再追加到目标导图或作为新导图打开，不覆盖期间的手工修改。领取互斥及已加入标记防止重复追加；整次加入可一步撤销。领取图片结果时将原图复制到导图媒体，节点“出处”可查看完整正文及原图，后续提问关联员和回答员共享这些完整依据。媒体列表标注“识别依据”，删除原图时明确提示对应影响。清理后台任务后，已复制的导图媒体与正文记录仍保留。

## 源码与部署

- `text-tasks.cjs`：文字／图片任务创建、原图上传、识别稿修订。
- `text-task-plan.cjs`：全文片段定位、覆盖与依赖校验、提示输入与结果校验。
- `text-worker.cjs`：独立Node进程识别／拟稿、规划、按单元生成和复核；图像读取使用原生Canvas，不依赖浏览器动画帧。
- `text-task-ui.js`：输入来源、图片选择、可选正文和规划编辑。
- `lecture-tasks.cjs`／`lecture-task-ui.js`：与讲义共用持久队列、暂停继续、任务列表与结果领取。
- `prompts/text-recognize.md`、`text-plan.md`、`text-extract.md`：新增可查看的提示词。

任务仍存储于私有 `.local/lecture-tasks`，可用 `MM_LECTURE_TASK_DIR` 指定。原图以来源编号 `.asset` 保存，不使用用户文件名构造路径。纯文本不依赖PDF运行时；图片识别需要项目已有的原生Canvas依赖。部署须同步更新前后端，重启本地服务并强制刷新页面。

上线多用户／多进程服务器仍需用户与课程权限、任务及密钥隔离、持久队列、进程间幂等与事务、配额和对象存储。交接队长时继续提醒 [服务器部署待办](server-deployment-handoff.md)。本次未推送或部署服务器。

## 验证

`verify-text-task-plan.cjs`、`verify-text-tasks.cjs`、`verify-text-tasks-ui.cjs` 覆盖全文无裁剪、规划覆盖与依赖、来源类型、可编辑识别稿、原图实际发送、语义单元回读、分节复核、关闭浏览器继续、服务重启、停止继续、原编辑保留、来源核对及撤销。测试仅使用隔离资料、独立端口与本地假模型；图文识别的实际准确率与耗时仍需用用户配置的真实模型验证。
