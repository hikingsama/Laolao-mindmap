# 本地后台讲义生成

## 使用

安装Node.js 22.13或更新版本。在项目目录执行一次 `npm ci --omit=dev --ignore-scripts`，之后按原方式启动项目服务。Windows本机已配置依赖时不需要每次重新安装。依赖固定为PDF.js 6.4.299及其兼容的@napi-rs/canvas 1.0.10，按package-lock.json安装，不混用其他版本的原生绘图库。

“课件 / 讲义生成导图”保留原文件选择、读取方式、主题融合/讲义分支、学习背景及补充选项。开始后先上传全部原PDF，界面明确提示上传进度。收到“已提交本地后台任务”后，可以切换标签页、最小化或关闭整个浏览器；本地服务和电脑仍须保持运行、唤醒并联网。上传未完成时关闭网页，材料不能凭空补齐；停止并重新提交即可，未提交的任务不会调用模型。

顶栏“后台任务”显示进行中、待核对和待领取数量。重开网页可查看进度、全部生成过程、停止或继续任务。原始PDF、全文索引、计划、阶段输出和最终结果由本地进程保存。无需保持网页轮询，后台仍会推进。停止只在明确点击“停止任务”时发出，关闭网页不等于停止。

完成时若原页面仍打开且目标导图仍在当前画布，会尝试一次自动加入；否则在“后台任务”点击“打开目标导图并加入结果”。结果以追加方式进入当前导图，保留原有正文和位置，可整轮一步撤销。原连接节点被删除、原导图打不开时，可选择“作为新导图打开”。嵌入PDF时将任务原件复制到导图附件；不勾选嵌入仍需临时上传供后台读取，但不在导图中保留PDF节点。

已加入标记、领取互斥及任务编号避免重复打开导致重复生成或重复追加；再次选择“作为新导图打开”是用户明确创建另一个副本。正在编辑的草稿仍走原有恢复/保存选择，任务不会擅自覆盖或放弃草稿。后台完成不直接改写原导图文件。

## 中断、清理与费用

正常退出或意外中断本地服务后，原任务记录、PDF及已完成阶段仍保留。重新启动服务会将未结束任务标为“服务中断，待继续”，不自动补发模型请求。点击继续后复用已完成阶段。

若中断或停止发生在模型请求期间，应用不能确认上游是否已完成及计费。此时必须在界面点击“重试该阶段并继续”，才重新发送这一阶段，可能再次计费；后续完整阶段不重复发送。服务商模型或接口地址变化时不能悄悄混用新的配置继续原任务，请恢复原配置或新建任务。模型密钥只在父进程及子进程内存中使用，不写入任务JSON或导图。

任务默认保存在本项目 `.local/lecture-tasks`；测试或自定义目录用 `MM_LECTURE_TASK_DIR`。若设置了 `MM_STORAGE_DIR` 而未设置任务目录，任务保存在其父目录的lecture-tasks子目录。独立结果和原PDF会保留，直到用户在任务列表点击“清理任务资料”并确认。清理会删除此任务的原件、进度和独立结果，已经加入导图的节点及已嵌入的附件保留。运行中或正在领取的任务不能直接清理。

## 实现与边界

- `lecture-tasks.cjs`：本机来源校验之外的任务接口、完整上传、队列、父进程持有锁、停止、恢复、领取互斥和清理。一项任务同时只有一个子进程，本地队列串行，最多8个未结束任务。
- `lecture-worker.cjs`：独立Node子进程完成全文通览、全局主题计划、完整单元回读、数学检查及结构复核，每阶段原子记录。网页不会负责启动下一批。进程重启不假设模型请求能精确续传。
- `lecture-pdf.cjs`：官方Node兼容PDF.js及原生Canvas读取/渲染PDF，不启动隐藏浏览器。每份PDF最多50 MiB，本次合计最多512 MiB、32份；语义索引和单元输入容量沿用现有限制。
- `lecture-task-store.cjs`：私有任务目录与原子JSON写入；原PDF使用文档编号作为文件名，用户文件名仅作为资料名称。
- `lecture-task-ui.js`：提交、只读进度显示、独立结果领取与画布追加。网络中断、重新打开、切换导图不会在后台自动重启任务。
- `ai-chat.cjs.run`：后台内部调用复用既有验证、提示词、用量和受限数学检查，不通过浏览器HTTP轮询调度。

文字、大纲、图片识别和按主题拟稿现已接入同一持久后台队列，详见 [文字后台生成](text-background-tasks.md)。普通节点问答及跨导图总结仍沿用各自原流程。服务端处理不依赖浏览器，云端理解仍调用用户已配置的大模型API。没有新增或部署远程服务器。

验证：`node tools/verify-local-lecture.cjs`；浏览器验证 `node tools/verify-local-lecture-ui.cjs`（需Playwright与Edge）。测试使用独立目录、独立端口及本地假模型，覆盖无浏览器完成、关闭整个浏览器、重开领取、保留编辑、撤销、秘密信息排除、停止、服务重启和阶段复用。旧浏览器测试入口默认转到本流程；`--legacy-browser-flow`只供旧版网页调度的历史复现。

**交接队长时务必同时提供：[服务器部署待办](server-deployment-handoff.md)。本地后台化完成不代表已经满足多用户服务器部署要求。**
