# 导图库、引用与双画布

## 左侧导图库

左侧列表可直接打开导图，无需先回首页。点击名称在当前激活的画布打开；单画布时名称右侧显示“已打开”，分屏时显示“左侧打开 / 右侧打开”，绿色边框标明当前操作的画布。

- 顶部可搜索导图名称或文件夹。
- 每个文件夹右侧显示导图总数（含子文件夹）；空文件夹显示0，折叠或搜索不改变总数。未分类显示未归类导图总数。
- 点击“新建文件夹”，在当前选中的文件夹下创建子文件夹；选中“未分类”时创建顶层文件夹。
- 拖动导图到文件夹可移动归属；文件夹本身也可拖动到其他文件夹。
- 文件夹的右键或“⋯”菜单提供重命名、移动、选择其中导图和移除功能。
- **移除文件夹保留内容**：直接包含的导图、子文件夹移到上一级；导图文件不会被删除。
- “多选”进入集中管理，下方显示已选数量、全选／全不选、移动到文件夹、多图总结、删除。“取消多选”退出并清除选择。
- 没有搜索时，全选包括折叠文件夹内的导图；搜索时只作用于搜索结果。管理选择不再限制为8张；多图总结仍支持2–8张。
- 单张导图的右键或“⋯”菜单也能删除；删除会将导图、未保存草稿和附件一起移入回收站。
- 侧栏底部的“回收站”可以恢复原导图，保留编号、附件、草稿及原文件夹归属（原文件夹已移除时放在未分类）。已有引用卡片保留，恢复后可继续跳转。回收站不会自动清理。
- 拖动侧栏右边缘调节宽度；左上角“‹”收起，画布旁“☰”重新展开。

文件夹只是导图库内的归类。移动和改名不改变导图编号，已有引用仍有效。归类保存在 `storage/maps/.library.json`，备份导图库时应连同它一起保留。

## 引用卡片

从左侧列表将导图拖到画布，松手的位置就是引用卡片的位置，拖动期间显示卡片轮廓。拖入引用不会移动原导图的文件夹归属。

也可以用画布操作栏或空白处右键的“引用导图”：选择目标后进入放置状态，再点击画布确定位置，Esc取消。更换已有卡片的关联目标则保留卡片原位置和尺寸。

**单击选中，拖动移动，双击打开目标导图。** 缩小查看时仍保留链接标识；右键菜单提供打开、分屏打开、更换关联及定位到左侧列表。“删除引用卡片”只移除这张卡片。

## 双画布对照

引用卡片的“分屏打开”按钮、右键菜单，以及左侧导图的右键菜单，都能将目标图放到另一侧。

- 最多两个画布，左右各自浏览、缩放、编辑和保存。
- 点击哪一侧，哪一侧就是当前操作对象；左侧列表打开导图和顶部设置入口跟随当前画布。
- 中间分隔条可拖动调整比例；缩放比例保持独立，调整宽度时保留各自的视野中心。
- 同一张图已经打开时，直接定位到已有画布，不会重复打开两份编辑状态。
- 两侧都有内容时，继续“分屏打开”会替换另一侧，保留被替换导图的草稿与浏览位置。
- 标题栏左侧是“返回首页”和“保存 ▾”。保存只提交该侧导图；下拉提供保存并留在画布、保存并返回首页、放弃修改并返回首页。
- “上一张导图”明确表示该侧的访问历史，有历史时才出现。
- “结束分屏”关闭点击按钮所在侧的导图，保留另一侧并铺满工作区（左侧按钮保留右图，右侧按钮保留左图）。先检查两张导图，仅对有未保存修改的导图依次显示名称并询问“保存／不保存／取消”；无修改不询问。
- 选择取消会保留分屏；此前明确保存的结果保留。选择不保存时，等所有问题处理完才放弃修改，因此后续取消不会丢弃之前待处理的内容。保存失败也保留画布。
- “返回首页”检查两侧修改后回到导图库。自动保存的草稿用于恢复，不等于明确保存。
- 标题栏可修改导图名称；放弃修改会同时恢复最近明确保存的名称、节点和附件，并清空对应的撤销历史。

现有AI问答与生成仍作用于发起操作的那张导图；两张导图的提问记录和生成结果保持独立。非激活画布的提问面板会收起，输入草稿保留。

## 不同节点的右键菜单

| 类型 | 专属操作 |
|---|---|
| 文字，包括公式、AI回答和总结 | 正文样式、标记、进度、数学排版检查、自适应、提问 |
| 图片 | 查看图片、重命名文件、恢复原始比例、携带图片提问 |
| PDF | 打开阅读、重命名文件、携带PDF提问 |
| 导图引用 | 打开目标、分屏打开、更换关联、定位左侧列表 |

颜色、对齐、分组和删除等按适用范围共用。混合多选只显示共同可用操作。焦点在左侧列表时，键盘操作不会误删画布中的节点。

## 验证

`tools/verify-workspace.cjs` 使用临时文件检查归类、版本冲突及两侧的编辑保存；设置 `MM_TEST_JSDOM` 后还会运行实际页面脚本的交互检查。`tools/verify-workspace-browser.mjs` 使用独立端口、临时浏览器资料验证真实鼠标、拖放、分屏布局并输出截图。应用本身没有增加运行依赖。

## 概览图浏览

概览与详细图各自保留缩放和平移状态。概览内双指捏合或 Ctrl／Command + 滚轮以指针为中心缩放，双指滚动平移，也可拖动背景或卡片平移；拖动不会误触主题跳转。缩放范围与详细画布一致，为15%–300%。

左下角提供缩小、比例、放大和适应屏幕；Ctrl +／−／0 操作当前概览。点击主题仍跳转至对应详细内容，学习清单仍与详细图同步。窄窗口、手机和分屏也使用可平移缩放的树图。
