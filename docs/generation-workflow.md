# 导图生成流程

## 当前讲义流程：本地后台任务（2026-10-25）

下文的通览、规划、回读及复核现在由本地子进程连续执行，浏览器只上传原PDF、提交任务、显示状态及领取结果；网页不再启动下一批请求。上传完成后可关闭浏览器，本地服务和电脑仍须运行。生成结果独立落盘，完成后追加到目标导图；重开网页从顶栏“后台任务”领取。服务中断后手动继续并复用已完成阶段，未知模型请求在确认可能再次计费后才重发。见 [本地后台任务](local-background-tasks.md) 及 [交接队长的服务器待办](server-deployment-handoff.md)。

适用：AI大纲/正文生成导图，以及一份或多份PDF课件/讲义生成导图。复用顶栏已有模型配置，不添加第二套配置。

1. **选择资料与方式**：文字可粘贴大纲、正文或笔记；PDF可多选、排序，选择按讲义分支或跨讲义融合，并逐份选择是否“嵌入到导图”。默认依据原资料，允许补充时单独标明。
2. **全文通览与计划**：文字作为当次完整输入；PDF先通览所有可读文件的全部页面，提取文字并按读取方式发送页图，建立题目、概念、证明及前后承接的内容索引。通览可分窗口传输，但不直接生成知识节点。收齐全部索引后统一规划主题、完整内容单元及直接依赖；索引必须恰好全部归属，不能遗漏或重复分配。
3. **回读与提炼知识节点**：PDF依据计划回读完整原文及页图，以完整题目、概念或自然子论证为生成单元；融合可跨页、跨文件对应题干、选项与答案，分支模式保留文件边界。后续单元携带所依赖单元的完整正文，承接符号与中间结论。模型生成完整知识单元、分节小标题、分步推导、分行公式、简明brief、主题、父级和语义连线；PDF节点携带文档ID和页码。程序校验身份、连接和出处，完整且已通过检查的节点流式进入画布。
4. **数学排版检查**：先做本地上下标、LaTeX与符号检查；只有疑点时才额外请求当前模型。模型只能为原表达式补定界符，程序限制修改范围；存疑节点等待检查，失败保留原文并标记“公式待检查”。不会替用户更改数值或推导。
5. **主题组织**：融合已在全文计划及原文回读时完成，不再把各批正文截成摘要反复生成。按计划统一主题名，各内容单元的完整正文都进入导图；详细结果及出处也保存在记录中，可之后定位或展开。资料不一致或无法辨认时单列待核对，不猜补缺项。
6. **整图结构复核**：全轮结束后，汇总本轮节点ID、标题、简述、父级与目录线索。模型检查同义/碎片主题、尺度不一致和主次层级，输出“中心→主模块→子主题”与归属理由，并审查学习顺序、给出排序依据。通常额外一次调用；超过100节点时分层复核。不重读或重发PDF。
7. **程序验证和应用**：每个原ID必须恰好出现一次，禁止遗漏、重复或未知节点；代表节点必须来自本组。合格方案只调整归属、父级及内部包含边；正文、公式、例题、出处及推导/关联边保留。复核失败或超时，保留原结构并说明原因；停止会中止实际请求。
8. **形成共享视图**：清理已完成的过程占位节点，以同一结构生成简明三级概览，以及双侧主题树、层级底色、曲线和现有分组底框。程序按模块数组显示顺序编号，左列从上到下读完，再读右列从上到下，不因节点大小打乱。模型负责语义，本地程序负责坐标、色板与接点。点击概览可定位详细分支。
9. **保存、追溯与撤销**：保留全文索引、主题步骤计划、来源、已通览/已整理两种页码范围、模板版本、实际输入输出、复核理由与失败原因。一页上所有计划单元完成才算该页已整理。本轮生成、原PDF、结构应用和整理仍能整体撤销；生成期间手动改过的位置和颜色优先保留。正式保存后可重开调查。

已有导图通过工具栏“结构复核”主动触发步骤6–8，先看方案再应用；支持一步撤销。预览后节点被编辑、删除或导图切换，旧方案不得应用。“自动整理”只按已有关系本地重排，不发模型请求。

“按原大纲”是本地层级导入，不执行AI提炼及结构复核。节点提问仍走“关联与定向→生成回答→按需数学检查→入图”的原工作流，不在每次追问后重审整图。

提示词位于项目prompts目录，目前注册12个任务模板，正文生成另外共用content-sections.md。lecture-survey.md建立索引，lecture-plan.md安排全文主题与步骤，lecture-extract.md回读并整理完整单元；lecture-merge.md仅保留旧版调用兼容。structure-review.md负责全局结构复核，math-review.md负责数学排版。顶栏“提示词与过程”可调查实际调用。结构复核不保证固定模块数，优先参考真实课程目录及内容关系。

全文索引超过200000字符，或一个内容单元原文与依赖前文合计超过60000字符、需要超过24张页图时，明确停止并保留记录，不以截断或改按页面生成兜底。实际容量仍由所选模型限制。新流程增加通览、计划和原文回读时间；修改服务端代码后须重新启动本项目并刷新页面。已保存的旧图不会自动改写。

PDF页图准备使用不依赖动画帧的离屏渲染，通览与原文回读均生效；普通PDF阅读器保留原显示方式。后台定时器节流仍可能延迟后续请求，页面冻结或关闭后继续生成需要服务端任务改造。本修复不增加模型调用；完整刷新页面以加载新PDF.js资源。见[PDF后台渲染说明](pdf-background-rendering.md)。

生成完成后，详细画布的模块节点旁及概览为已复核的各二级模块提供“通览结构→精读提炼→串联关系→主动复现→应用自检”五步手动清单，中心汇总完成情况。它属于学习过程，不属于模型生成阶段；AI生成完成不会自动勾选。复现可以是复述、画图或关键推导，自检可以用题目、案例或反例，并回资料核对。与节点解题清单独立，勾选和展开状态随导图保存。

详细清单默认展开，自动布局预留其空间；旧坐标保持。两个视图共享学习状态和整讲汇总，并支持从详细节点定位概览模块/子主题、再返回详细分支。切换只改变浏览方式，不新增模型调用，不新增知识节点。
